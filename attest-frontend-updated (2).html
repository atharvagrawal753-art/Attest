    What PS 2026262 asks for

    Organisation: AICTE · Category: Software. Attest addresses the three components of the problem statement.

    Approval workflow automation

    Moves each application through submission, scrutiny, expert review and decision, with defined roles and statutory timelines.

    Compliance monitoring

    Tests institutions against a configurable rule set, before approval and continuously after it, and shows the evidence behind every result.

    Alert management

    Raises alerts for overdue stages and compliance lapses, and escalates unattended alerts to the next level of authority.

    From submission to monitoring in five steps

    Each step is visible to the officer and recorded, so nothing is a black box.

    1

    Submit

    Institution files the application.

    Accepts PDF, JPG and PNG. Each file is stored with a SHA-256 hash so later edits are detectable.
    2

    Scrutinise

    Documents are read and cross-checked.

    Text is extracted from every document and each field is compared across files. Every value keeps its page.
    3

    Review

    Officers and experts examine the evidence.

    Disagreements show both values side by side. Every stage runs against a statutory timeline.
    4

    Decide

    Decision is issued with reasons.

    Approval is blocked while a mandatory document is missing, unless an authorised officer records an override.
    5

    Monitor

    Compliance is watched after approval.

    Rules run on a schedule. Expiring certificates and breaches raise alerts that escalate if no one acts.

    Cross-document matching

    Shows exactly which fields disagree and where each value was found.

    Authenticity signals

    Flags possible alterations or odd metadata. These are warnings for a person to examine, not proof of fraud.

    Explainable rules

    Every warning names the rule, the evidence found, and what the reviewer should verify.

    The competent authority decides

    Attest recommends. An authorised officer approves, rejects, or requests corrections, and every decision is recorded with a reason in a tamper-evident audit trail.
